# Playwright features extracted from the intro docs

This list captures the main Playwright features and related documentation links referenced from the intro page.

- [Writing tests](https://playwright.dev/docs/writing-tests) — learn how to author tests with Playwright.
- [Running tests](https://playwright.dev/docs/running-tests) — run tests locally or in CI, including headed mode, sharding, and retries.
- [Code generation](https://playwright.dev/docs/codegen-intro) — generate tests by recording browser actions.
- [Trace Viewer](https://playwright.dev/docs/trace-viewer-intro) — inspect test execution with DOM snapshots, network activity, and screenshots.
- [UI Mode](https://playwright.dev/docs/test-ui-mode) — run tests in a visual, interactive mode with debugging tools.
- [HTML Reporter](https://playwright.dev/docs/test-reporters#html-reporter) — view test results in a browsable HTML report.
- [VS Code Extension](https://playwright.dev/docs/getting-started-vscode) — run, debug, and generate tests from VS Code.
- [Test configuration](https://playwright.dev/docs/test-configuration) — configure browsers, projects, retries, timeouts, and reporters.
- [Locators](https://playwright.dev/docs/locators) — find elements with resilient, user-focused selectors.
- [Assertions](https://playwright.dev/docs/test-assertions) — verify page state using Playwright's built-in assertions.
- [Fixtures](https://playwright.dev/docs/test-fixtures) — share setup and teardown logic across tests.
